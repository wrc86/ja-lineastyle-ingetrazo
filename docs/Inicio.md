## Instalación rápida

1. Descarga `ja_lineastyle-0.1.3-plugin.zip` y descomprímelo.
2. En IngeTrazo abre **Extensiones → Abrir carpeta de plugins**.
3. Copia la carpeta `lineas_color` completa y reinicia el programa.
4. Abre JA LineaStyle desde **Extensiones**.

El ZIP es para IngeTrazo, no un RBZ para SketchUp. Al actualizar, sustituye la carpeta correspondiente y evita copias duplicadas.

## Ayuda

Si la extensión no aparece, comprueba que `lineas_color/__init__.py` esté directamente dentro de la carpeta del plugin, que los iconos se hayan copiado y que hayas reiniciado IngeTrazo. Para un reporte incluye versión del programa, versión de la extensión, sistema operativo, pasos y resultado esperado.

## Procedencia

Separado del [repositorio conjunto](https://github.com/wrc86/ja-ingetrazo-extensions), conservando el historial de su carpeta. La versión 0.1.3 corrige la compatibilidad con el binario macOS de IngeTrazo 0.5.7 y se publica en este repositorio independiente. Las capturas proceden de los paneles reales del entorno de desarrollo; el muestrario de LineaStyle fue aportado por Julio Angulo.

Esta documentación es la base para la futura wiki del proyecto.
